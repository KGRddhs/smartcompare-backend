Results — Category Structure

One shell, nine categories. The Results layout is fixed; the data is per-category. Each comparison renders its own dimensions, its own ordered fields (which drive both the “Specs” table and the “At a glance” curated list), and its own price-comparability (“like-for-like”) basis.

These are the canonical structures the backend emits — the design agent should build category results from these, not invent dimensions or specs.
