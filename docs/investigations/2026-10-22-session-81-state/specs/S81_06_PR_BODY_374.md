### What it does
`app/services/llm_router.py` sits ABOVE `api_budget_service.guarded_llm_create` (unchanged; U3c and K1 untouched). Every one of the 16 chat sites calls `_llm_router.route("<site>", _llm_breaker.guarded_llm_create, client, <the unchanged kwargs>)`. Role flag OFF: the first statement returns the exact base call. Role flag ON: consent >= 3 -> Claude Haiku 5.5 through `guarded_anthropic_create` (key check, S81-04 spend admit, its own `circuit:anthropic` breaker off the loop, typed-exception classification, an inner deadline, the S81-03 llm ledger, refusal recorded before raising) returning an OpenAI-shaped result; consent absent / < 3 -> the exact OpenAI call while ENABLE_OPENAI_PRE_V3 is ON, else ConsentUpdateRequiredError. Both text entries, /url/compare (before the reserve) and the camera (before identify, for any reached role) refuse such a request with the existing coded 503 LLM_UNAVAILABLE. Under any role flag ON a verdict LLMUnavailableError is a non-delivery (REST, stream, URL, camera). Moderation on Claude fails CLOSED on every failure class (a refusal, any dispatch failure incl. a client-construction error, malformed JSON, a parseable answer whose `flagged` is not a bool (RB6-4), any other exception in the classifier step). A client-construction failure (`_client_for` / the factory: an ImportError, a constructor error) is a terminal `AnthropicDispatchError(<type name>, None, False)` with a held half-open probe released, logged by type only. A terminal 4xx records breaker success only for a held half-open probe (F1-8; pinned for the CLOSED breaker by RB6-3). One Sonnet escalation per compare.
