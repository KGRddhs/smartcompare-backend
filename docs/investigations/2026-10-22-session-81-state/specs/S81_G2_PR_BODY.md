## The mode idiom (all three flags, R-G2-1)
`kb_seed_common.run_mode(flag)` is the FIRST statement of every entry: unset / blank / garbage / `false` / `0` / `no` / `off` / `dry` -> **OFF** (one INFO line carrying the mode and the flag, exit 0; nothing read, no client, no fetch, no SDK import); `true` / `1` / `yes` / `on` -> **DRY RUN** (reads and counts, writes nothing); the exact word `apply` -> **WRITE**. A CLI `--dry-run` downgrades `apply` and never upgrades OFF. Only `apply` writes.
