## 2. The contract
### 2.1 Part 1, W = ENABLE_IMAGE_GUARD_WORDS (reader `IR.guard_words_enabled()`, house idiom)
Read per call inside `check` only, and only after the base verdict is None (so never under G OFF, where no RelevanceCall exists, IR:597-600 / IMG:364-365). OFF: `check` returns exactly the base verdict (the S dispatch included).
ON, after a None base verdict, `_words_reason(ident, texts)` on the FIRST text only (the title at every call site: KG title, organic title, images title, Serper title; the second text is the source name, never tested, so "The Body Shop" or "Bath & Body Works" as a source does not refuse):
1. `form`: a title token (`fold_numero(_cg.normalize(title[:512]))`) in FORM_WORDS that is not in `ident.query_words` -> "form". FORM_WORDS (folded with `_fold`, ASCII source, Arabic by `_cps` code points):
   - body: deodorant(s), deo, antiperspirant, shower, gel, lotion, balm, aftershave, shave, soap, cream, mist, oil, body, hair, bath, wash, scrub, powder, candle, diffuser; Arabic deodorant, gel, shower, hair, lotion (code points in the notes-folder words.py).
   - gift: gift(s), giftset, set(s), coffret, kit, bundle, duo, trio; Arabic set, gift, gifts.
   - refill: refill(s), recharge ("refillable" is one token and never matches).
   - travel / mini: travel, mini(s), miniature(s), atomiser(s), atomizer(s), purse, vial(s), sample(s), decant(s), rollerball; Arabic travel, sample.
2. `concentration`: (a) the token `intense` in the title and not in `ident.query_words`; else (b) when `ident.query_conc` and the title's labels are both non-empty and share no label. Labels by `_conc_labels(text)`: longest-first phrase scan over the folded tokens with the resolver's table (product_resolver.py:77-90: extrait de parfum, parfum intense, eau de parfum, eau de toilette, eau de cologne, eau fraiche, edp, edt, edc, extrait, elixir, parfum) plus the Arabic EDP / EDT / Parfum / Elixir / Extrait phrases; a `parfum` directly after `elixir` or `extrait` is absorbed ("Elixir Parfum" = Elixir). Lenient on purpose: "Sauvage Eau de Parfum - Parfum Homme" (EDP + Parfum) passes an EDP query; a stricter "every title label typed" rule refuses it and gains nothing on the corpus.
3. No query concentration (R OFF, "Dior Sauvage" typed) -> rule 2(b) is skipped; form words and `intense` still apply.
Identity (filled always, read only with W ON; dataclass defaults keep every existing construction valid): `query_words` = folded tokens of `product_name` and of the line; `query_conc` = `_conc_labels(product_name) | _conc_labels(line)`. `product_name` is the full name (section 1), so R ON gives the resolved concentration and R OFF the typed one; no change to `relevance_kwargs`, its dict or any SCS call site.
Reasons: `IR.REASONS` gains "form", "concentration" (the I1 REL_LINE regex, tests/test_inc_i1_picture_must_match.py:66-71, holds while W is OFF). Order: brand, name, fragrance_word (base), then form, then concentration. Every guarded tier gets it via `check` (`accept`, `_organic_reason`, `organic_passes`, `accept_pick`); `accept_scheme` has no text, unchanged.
