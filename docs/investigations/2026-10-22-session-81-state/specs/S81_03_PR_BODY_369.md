## Stated limits

3. The llm ledger is bound by S81-06; until then `record_llm_call` is a no-op and `metadata.llm` holds OpenAI calls only.
4. The match is by (prompt, completion) tokens: two calls with identical counts on different models can swap prices (the sum is exact when both are tracked).
5. The Haiku long-context tier, the Sonnet 200,000 boundary and every Anthropic row are re-verified by S81-07's pricing read BEFORE the first Anthropic flip (a difference lands as a data PR); both boundaries are pinned (A9: Haiku 100,000 flat, 100,001 tier; A9b: Sonnet 150,000 and 200,000 flat, 200,001 and 199,999 + 2 cache read unpriced).

7. An Anthropic usage without the `cache_creation` breakdown counts every cache write as 5-minute.
8. The Batch rate applies only to records flagged `batch` (none before S81-16).
9. `metadata.llm` adds about 1 KB per persisted comparison (bounded by the distinct models; 786 bytes for 11 calls on 2 models, measured by the correctness adversary).

11. Link-mode compares are never persisted (#340); no admin view reads `llm_spend_ledger` yet.
