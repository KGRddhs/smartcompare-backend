## IT26-4 THE FINDING: FOUR RE-WORDED SENTENCES CANNOT BE TRUTHFUL ON THEIR OWN
(i) "Nothing is shared any more, because the credentials are revoked" contradicts (a) in the same document: a service that refuses every request does not "process some or all requests". (ii) "MYEZ no longer sends data to OpenAI" is false while F3 holds. (iii) Silence about the programme beside (a) would drop a disclosure the live policy makes, while the enrolment continues. So a truthful text without the switch has to settle what OpenAI's CURRENT role is, and there are exactly two ways to do it.
