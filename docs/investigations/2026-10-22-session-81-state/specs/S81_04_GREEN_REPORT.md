Design notes (each a reading of the rulings, stated for the adversaries):
- Memo (R-S04-1): per lane `{day, base, read_at}` (the last Upstash total this process observed) plus an in-flight sum per (lane, day) of the record deltas submitted and not yet landed; the view is base + in-flight (so a delta counts at once, r39b). A GET replaces the base; an EVAL total only moves the base up (concurrent writes can return out of order); each record job settles its own in-flight delta exactly once on its pool thread, even after its awaiter gave up; a state generation makes a job finishing after a test reset a no-op. Overlap errs toward overcounting (refusing slightly early), never undercounting.
- Bounds (R-S04-2): async callers `asyncio.wait_for` over the `llm-spend` pool future (records shielded = durable); the sync callers (`admit`, `record`, `reserve`, `settle`: scripts, workers) run on the same pool under `future.result(timeout)`. `_client() is None` returns before any submit.
- GC-3: `LLM_SPEND_FALLBACK_OUTPUT_TOKENS = 16384` (also the default output bound); `fallback_bound_usd(provider)` = the conservative rate at that many output tokens; `admit` (no provider) uses the unknown-provider (Sonnet 5.5) branch; the conservative row is the most expensive row of the provider's S81-03 table (4o / Sonnet 5.5 today; no model literal in the leaf).
- GC-4: `record_openai_response_soon` records the list price when the model is priced and the response carries a usage, else the admitted bound (an unpriced model, a usage-less response); a raising / cancelled create never reaches it.
- GC-6: `lane_exhausted(lane, spent)` = spent + `LLM_SPEND_ENTRY_RESERVE_USD` >= cap is the one predicate of the entry check and the /health snapshot (the snapshot reports `exhausted` False for a memo of an earlier Riyadh day; its `day` field shows that day).
- GC-9: `RECORD_SCRIPT` ARGV [delta, expireat]; `RESERVE_SCRIPT` ARGV [upper_bound, cap, expireat] (GET, refuse with nil when cur + ub > cap, else INCRBYFLOAT + EXPIREAT). `reserve` returns True when the bound is held, None on a fail-open (contract: settle only after True, else record).
- R-S04-7 / GC-5: `/health` via `app.main.llm_spend_health_snapshot` (the `_module_snapshot` shape): `{}` until the breaker ran, then `llm_spend` (possibly `{}`) + `llm_spend_fail_open`; admin `spend_breaker` = `admin_snapshot()` only ON.
- The chokepoint passes six `kwargs.get(...)` values (U3c T01b/T01c unchanged); `spend_ticket` is a local; both served tails record after `record_openai_response`.
