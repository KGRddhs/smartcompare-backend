## 9. Stated limits
- L-LINK: comparison_id is set only on the text exits with ENABLE_COMPARISON_ID_ECHO ON and a signed-in user (1.3); camera / URL runs and echo-OFF runs carry comparison_id NULL, so the deletion hook reaches only kb_feedback rows whose request id belongs to a run linked to one of the account's comparisons; the rest age out with the 365-day kb_prune_feedback.
- L-DELIVERY: delivery exits only; refusals, timeouts, error terminals and undelivered partials write no run row (S81-22b).
- L-NULLCTX: with ENABLE_REQUEST_CONTEXT_HEADERS OFF (production today) or no pepper, consent / request id / device key / query_hmac are NULL and the judge skips the run.
- L-ESCAP: the escalation caps leave candidates pending (judged_at NULL, flags escalation_capped); the owner reads the share.
- L-EST: estimated_input_tokens = bytes / 4 is an estimate, labelled; the real count comes from the batch usage.
- L-WEB: no web search (INERT flag).
- L-SC: ENABLE_SELF_CRITIQUE untouched (R-S22-12).
- L-TRUST: the judge trusts the stored snapshot (it never re-fetches); a snapshot cut to the minimal form is unjudgeable.
- L-IDTEXT: camera / URL runs hash the pair's identity text while text runs hash the typed query, so a text run and a camera run of the same pair do not match for the re-compare / 2-device rule (Q2).
- L-BATCH29: Anthropic keeps Message Batch inputs / outputs up to 29 days (PLAN_S81 :114; not ZDR); the batch body is the de-identified snapshot only.
- L-OTEL: the OpenTelemetry GenAI names are R-S22-6's, not verified against the published conventions in this spec (no documentation fetch was granted); gen_ai.usage.input_tokens excludes cached input here (Q5).
- L-VERDICT: the verdict prose in the snapshot is the delivered text; when personalization shaped it (cohort / profile context in the verdict prompt) the prose can reflect that context in words, although no personalization FIELD is stored.
- L-FORGE: anonymous /feedback can be forged (PLAN_S81 Standing risks): a forged 'wrong' can only trigger an escalation inside the caps, never a correction.
- L-KBID: kb_product_ids is NULL in this unit (Q4).
- L-INLINE: with ENABLE_SYNC_DB_OFFLOAD OFF the insert's blocking `.execute()` runs on the loop inside the background task (the same as every house fire-and-forget write); the admin client is memoised.
