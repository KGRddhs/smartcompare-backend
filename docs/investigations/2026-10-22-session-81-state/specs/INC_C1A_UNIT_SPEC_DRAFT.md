## 1. Why
The data lane's INC-P2 PRICE-NOT-LOST (dark ENABLE_PRICE_NOT_LOST) shows two prices for different bottle sizes only to an app that declares it can draw a size. No bundle draws a size today: `git grep size_ml|per_ml|pair_price_sizes SmartCompareApp/src` is empty at b0ad2603, and `CLIENT_CAPABILITIES` (SmartCompareApp/src/services/requestContext.ts:38) is an empty list, so no X-Client-Capabilities header is sent.

## 2. The wire this unit reads (INC-P2_UNIT_SPEC.md at docs/incident-2026-11-11 cc8f9737, section 2.5 and its table; RULINGS_INC_P2.md; X1-R11). All are ADDITIVE and may be absent:
- `price.size_ml`: int, on a SHOWN fragrance price (amount a number > 0, `unavailable` not true) whose own listing has exactly one strict size token. Carried on `products[i].price`, `overview.products[i].price` and the SSE `prices` payload.
- `price.per_ml`: float, `round(amount / size_ml, 4)`, in the PRICE'S OWN CURRENCY per ml; present only with `size_ml`. Display precision is the client's (X1-R11).
- `metadata.pair_price_sizes`: `{"mode": "same_size" | "different_sizes" | "unknown", "sizes_ml": [int or null, int or null]}`, fragrance pairs of two.
RULED by the orchestrator (2026-11-16 20:50; RULINGS_INC_P2.md section G, filed with the data lane's RED gate: re-read it at the RED and take every shape from it): (1) `size_ml`, `per_ml` and `metadata.pair_price_sizes` go to every app when ENABLE_PRICE_NOT_LOST is on; (2) the `price_size` token decides one thing only: a price for a different bottle size than the other side's is placed in `price.amount` when the token is present, else the side stays pending and the listing travels in `price.offsize_listing` (this app declares the token, so it draws `offsize_listing` nowhere in this unit); (3) frozen names: `size_ml`, `per_ml`, `offsize_listing`, `metadata.pair_price_sizes`, the token `price_size`. The different-sizes marker is the VALUE `"different_sizes"` of `metadata.pair_price_sizes.mode` (INC-P2_UNIT_SPEC.md section 2.5, cc8f9737 line 223), not a key; if section G changes that shape, section G wins.

## 3. The contract (no flag: a client unit is gated by the over-the-air publish; every new line renders only when its key is present and valid, so with today's server every result renders byte-identical text)
1. `CLIENT_CAPABILITIES = ['price_size']` (requestContext.ts). The header `X-Client-Capabilities: price_size` then rides every request that already builds context headers. `price_asof` is NOT declared in this unit: declaring it switches a server behaviour (`kb_serve.client_price_asof` -> `kb_price_asof`, the KB-served dated price) and the owner's dated wording ("Last checked N days ago") belongs to INC-C1. Pin: `kb_serve.client_price_asof` is unaffected (server unchanged; a jest row asserts the header value is exactly `price_size`).
2. The price line of each product card (ResultsContent.tsx `formatPrice` and its render site; find by text): when the price is shown and `size_ml` is a finite integer in 1..9999, the amount line becomes `results.price.withSize` = "{{price}} · {{size}} ml" (EN) / "{{price}} · {{size}} مل" (AR [NATIVE READ]), `{{price}}` = today's exact formatted amount (formatAmountWithCurrency, the converted label kept after it, once), `{{size}}` through the app digit policy. Otherwise today's text exactly.
3. A per-ml line under that price, only when `size_ml` is valid AND `per_ml` is a finite number > 0: `results.price.perMl` = "{{price}} per ml" / "{{price}} لكل مل" [NATIVE READ], `{{price}}` = formatAmountWithCurrency(per_ml, price.currency, t) BUT with 4 decimal places for a 3-decimal currency (BHD 0.5811) and the currency's minor unit + 2 otherwise (the RED agent measures what formatAmountWithCurrency allows; the spec review may simplify to the minor unit + 1). No client computation of per ml: no `per_ml` key, no line. Style: the existing caption style (`styles.convertedCaption`), testID `results-product-perml-<idx>`.
4. When `metadata.pair_price_sizes.mode === "different_sizes"` and both prices are shown: one caption `results.price.differentSizes` = "Different bottle sizes, so we do not compare the prices." / "حجما العبوتين مختلفان، لذا لا نقارن السعرين." [NATIVE READ], once, under the price row (testID `results-price-different-sizes`). The client makes NO cheaper claim of its own anywhere (today it makes none: `getPriceDiff` is dead code, INC-P2 spec 1.5); the server owns the bars and the verdict.
5. Types (types.ts Product price): additive optional `size_ml?: number | null; per_ml?: number | null;` and metadata `pair_price_sizes?`. No other screen (History, Home smart pick, share) changes in this unit; the History row of a saved result draws what the saved body carries through the same card (state it).
6. i18n: en.json and ar.json gain exactly the three keys above (the strings of PAGE_DESIGN_V2.md section 7 table, design branch docs/incident-2026-11-11); the i18n parity fences hold.
