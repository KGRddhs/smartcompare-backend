#### 2.1 Flags and knobs

CLI `--dry-run`, `--report PATH`.

#### 2.2 Per host (sequential, one shared `PoliteFetcher`)
1. Gate the host: `url_gate(row, robots.origin + "/", now)` must be None (a live, fresh, allowing record on its origin), else the host's reason (`no_record`, `robots`, ...), no request.
2. Read `robots.origin + "/robots.txt"` through the `PoliteFetcher` with `gate=False` (robots.txt itself is not governed by robots) -> 2xx: the body; 404 / 410: `no_sitemap`; anything else, a timeout or an SSRF refusal: `robots_unreadable` (fail-closed), next host.
3. `declared = robots_eval.sitemaps(body)`; keep at most 5 URLs that are same-site (`sitemap_discovery_service._same_site(u, _bare_host(origin))`) AND allowed by `url_gate(row, u, now)`.
4. For each kept index URL: `slugs |= await sitemap_discovery_service._collect_slugs_for_index(host, u, fetch=D11_FETCH, max_children=PDP_DISCOVERY_MAX_CHILDREN, robots_fetch=REFUSE_ALL, robots_cache={netloc(origin): body})` where `D11_FETCH(url)` = the `PoliteFetcher.get(url, row, now)` body on 2xx (the per-URL gate on the persisted record, both agents, the origin; the SSRF hop check; the named-UA headers; no impersonation), else None; `REFUSE_ALL` raises (so a netloc not pre-seeded in the cache reads as unreadable: fail-closed) and is never reached for the host's own netloc because its body is pre-seeded. The PDP recogniser is the module's `_is_pdp_url`, so `ENABLE_SITEMAP_PDP_MARKERS_V2` decides whether Woo / Salla / Magento PDP shapes are collected (production state UNKNOWN; both states pinned).
5. The CDX leg (when `cc_cdx_enabled()` and `KB_CC_INDEX` valid): `GET https://index.commoncrawl.org/<KB_CC_INDEX>-index?url=<host>%2F*&output=json&fl=url,status,mime&filter=status:200&filter=mime:text/html&page=<n>` for n = 0, 1, 2 (at most 3 pages per host), through the `PoliteFetcher` with `gate=False` (the merchant is never contacted: the request goes to the index host only), timeout 30 s; each JSON line's `url` that is same-site and `_is_pdp_url` joins `slugs` under `_slug_from_pdp`; a 429 / 503 / non-2xx / malformed body ends the CDX leg for the RUN (`cdx_stopped`). CDX URLs are never fetched by D11.

#### 2.3 Ranked juices
`rank = for each kb_products id, the number of distinct kb_offers.merchant_id over its variants` (one paged read of `kb_offers` columns `variant_id,merchant_id`, 1000-row pages ordered by id; the product id = the variant id minus its last `|<ml>` field), ranked by count desc then id, the first `PDP_DISCOVERY_MAX_JUICES`; their brand and name from one `kb_products` read per 100 ids (`.in_("id", ...)`). A juice with no offer is not ranked. An empty KB ranks nothing (the dry run still reports the per-host discovery counts: the sitemap PDP density of each host).

#### 2.4 Matching (in memory; the service's own rules)
Per host, the in-memory token buckets of `build_sitemap_index` :627-639 (for each slug, every `_sanitize_token_key(token)` of `normalize_words(slug)`, capped at `_BUCKET_CAP`), then per ranked juice `query = brand + " " + name`: the first `_MAX_BUCKET_PROBES` of `_ordered_probe_tokens(query)` select buckets and `_match_sitemap_slug(<bucket as {slug: url}>, query)` returns the URL or None. An unranked or unmatched URL is never written.

#### 2.5 Writes (APPLY; `KbWriter.gaps`)
Per (juice, host) match: `build_gap_row(product_key=pid, field="pdp_" + sha256(host)[:16], first_seen=observed, last_seen=observed, demand_count=0, state="queued", source_hint=canonical_offer_url(url))`; a hint over 256 chars or refused by the builder -> skipped `hint_refused`. `upsert(on_conflict="product_key,field", ignore_duplicates=True)`; a row not returned (already present) gets ONE `update({"last_seen": observed})` filtered by product_key and field (the state, the hint and the demand of an existing row never move). ONE `observed` per run. D11 writes ONLY kb_gaps.
