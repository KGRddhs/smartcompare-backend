## B. The review's questions and the spec's open questions

- X1-R3 (C-4; question 2) A DESIGN CHANGE, not a stated limit: the eligibility test E4 compares identity WITHOUT the size axis. An off-size listing differs from the target on size by definition, so a typed size ("... 75ml") must not make every other size fail; without this the page would say "not listed" for a perfume a store lists at another size, the very falsehood this unit removes. Bounds: every other axis of the identity backstop still applies (a RED row: a typed 75 ml target against a 125 ml title of the same line is eligible and carries size 125 from the title; a second row: the same against a title of another concentration is refused); the chokepoint's own backstop call for SHOWN prices stays byte-identical (a PIN row); the amendment measures the least invasive way at the then-main (remove the size tokens from the name passed to E4 with the repository's existing size reader, or a keyword-only switch on the backstop) and reports back before the RED if neither is small.
