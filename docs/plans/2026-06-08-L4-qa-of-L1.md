## 4. Minor nit — supplements dosage label uses raw IU not multiplier

`_compose_delta_text("dosage", ...)` extracts `5000 IU` and `1000 IU`,
computes the 5× multiplier correctly, but the emitted label is
`5000× dose vs 1000×` (line 281 in scoring_service.py around the
`f"{hi:g}× dose vs {lo:g}×"` format). The `×` is intended as
multiplier notation but `hi` and `lo` are RAW IU/mg numbers (e.g.
`5000`), not the multiplier (`5×`).

**Suggested fix (1-line):** change

```python
return f"{hi:g}× dose vs {lo:g}×"
```

to

```python
return f"{multiplier:.1f}× higher dose"
```

OR drop the `×` notation entirely:

```python
return f"{hi:g} IU vs {lo:g} IU"   # when units are detectable
```

**Severity:** copy-polish, not blocking. Frontend bar chart already
carries the visual margin. Recommend hot-fix during the cross-QA window
OR backlog into A v1.1.
