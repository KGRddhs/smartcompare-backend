## Shared constraints (every lane reads this)

1. **REWRITE verb is required** — never "compose," "patch," "align," or "wire up." If the existing `.tsx` has different element order or section set than the JSX, tear it down and rebuild top-down per JSX. Cite the JSX line range in every commit message.
2. **DELETE list per surface is non-negotiable** — explicitly list stale Bundle D / Bundle E S2 pieces the JSX doesn't show, and DELETE them in the REWRITE. Do not preserve "in case it breaks something." If JSX doesn't show it, it goes.
3. **JSX is the source of truth** — when in doubt about styling / spacing / element order, JSX wins. Read the JSX completely BEFORE touching `.tsx`. Enumerate element order in your commit message body.
4. **TDD red-green-refactor cycle** — write the failing Jest/pytest test first, watch it fail with the right error, implement minimum, watch it pass, then refactor + recommit.
5. **80% statement coverage** on new code is the gate. `npx jest --coverage --collectCoverageFrom=<your-files>` for FE, `python -m pytest --cov=app.services.<your-modules> --cov-report=term-missing` for BE. Idle time goes to test authoring.
6. **No deferrals to "S4 polish"** — there is no S4. If an item is in your lane scope (per § A1-A4 below), it ships in S3 or your PR is rejected. Defer ONLY with explicit dispatcher approval in writing.
7. **No new native deps** — keeps the existing EAS build serving post-S3 OTA without rebuild. JS/TS only.
8. **No scary copy** — banned vocab per CLAUDE.md: EN `couldn't`, `try again`, `Failed to`; AR `تعذر`, `فشل`. No "estimated" in UI; use "indicative" or "reference."
9. **No backend internals in reveals** — per `memory/feedback_no_backend_internals_in_reveals.md`, tap-to-reveal panels show qualitative arrows/labels, never exact coefficients or per-dim shift math.
10. **Animation initial values must be SETTLED state** — per `memory/feedback_animation_initial_value_must_be_destination.md`, never `useSharedValue(±width)` and rely on useEffect for path-to-destination. Use `useSharedValue(0)` (settled) and snap-to-source inside the useEffect transition handler.
11. **Snapshot verify-before-regen** — per `memory/feedback_snapshots_as_staleness_liability.md`, if a snapshot fails after a structural fix, FIRST inspect the diff. Never blanket `npx jest -u`.
12. **alignItems:'center' child-collapse** — per `memory/feedback_rn_alignitems_center_collapse.md`, any animated wrapper containing flex:1 row children needs `alignSelf: 'stretch'` when any ancestor has `alignItems:'center'`.
13. **Path-restricted commits required** — `git commit -m "msg" -- <paths>` (NOT `git commit -- <paths> -m "msg"`). The `--` is a path separator.
14. **No skipping hooks** — never `--no-verify`. If a pre-commit hook fails, fix the issue + create a NEW commit (not amend).

Mirrors price_service.py tier architecture:
- Tier 1: Serper Images (paid, 1 credit / product)

- Tier 2: Firecrawl rendered scrape (paid, budget-gated)
- Tier 2.5: Scrape.do residential proxy (paid, budget-gated)
- Tier 3: GPT extraction from organic results (paid, ~$0.0005)
- Fallback: None — frontend renders placeholder

Budget gating: `api_budget_service.try_consume_serper_image_credit(1)`
returns False when daily budget exhausted; service falls through to Tier 1.5
and beyond without burning Tier 1 credits.

API budget counter: `serper_image_calls_today` (separate from
`serper_calls_today` so image pipeline doesn't starve price/spec).
"""

from typing import Optional
import logging
from app.services.serper_service import search_images

# ... existing imports for firecrawl, scrapedo, etc.

logger = logging.getLogger(__name__)

    product_name: str,
    *,
    region: str = "bahrain",

) -> Optional[str]:

    # Tier 1.5 piggyback — if page scrape already returned an image, use it (FREE)

        try:
            response = await search_images(product_name, num_results=1)
            images = response.get("images", [])
            if images:
                url = images[0].get("imageUrl")
                if url:
                    return url
        except Exception as e:
            logger.warning("[image] Tier 1 Serper Images failed: %r", e)
    
    # Tier 2 — Firecrawl rendered scrape (existing service, budget-gated already)
    # ... use existing firecrawl_service ...
    
    # Tier 3 — GPT extraction from organic results
    # ... use existing openai_service ...
    
    return None
